# 用户版新增功能：使用说明

## 进入应用

升级后使用原有账号登录本站 `/app/`。智能导入需要在模型设置中配置可用的 AI 服务。新增功能不包含演示账号、演示数据或预置 API 密钥。

## 功能入口

| 功能 | 从哪里打开 | 怎么使用 |
|---|---|---|
| 独立角色状态 | 进入对话 → 角色状态 | 选择角色并编辑；只改变本次故事。可选择同步角色卡更新。 |
| 导入查漏 | 素材 → 智能导入 → 打开草稿 → 查漏与原文复核 | 对照原文、字段引用和清理记录。未匹配内容保持待确认，可单段重新识别。 |
| 导入保存与继续 | 智能导入下方的已保存任务 | 查看日志、取消、继续失败分段、保存草稿。模型配置变化时停止旧任务，可恢复原配置或新建重新识别任务。 |
| 同名分段合并 | 打开草稿 → 合并同名分段 | 确认属于同一素材，逐项选择状态、分类等冲突。文字设定保留分段原文，原结果保留。 |
| 导入历史与撤销 | 素材 → 导入历史 | 先预览可撤销项。已修改、被对话或存档引用的素材保留；重复提交和撤销不会重复创建或删除。 |
| 完整角色卡 | 角色 → 编辑角色卡 | 保存完整设定、背景、场景、开场白、备用开场白及专属世界书。高级字段使用 JSON。 |
| 长设定分层 | 编辑已保存角色 → 长设定与核心确认 | 原文不截断。确认核心和必要段落，其他段落按关键词及预算选择；原文修改后需要重新确认。 |
| 实际设定记录 | 对话 → 本轮设定使用记录；AI 回复 → 本条回复的设定记录 | 查看生成请求当时的内容、用量估算和排除原因。后续编辑世界书不会改写旧记录。 |
| 记忆与锁定 | 对话 → 故事记忆 | 编辑事件记忆和锁定事实，查看修改历史，或提交后台重新总结。 |
| 存档与分支 | 对话 → 剧情存档 | 在当前或有状态记录的历史节点存档。可新建分支或回档；回档前自动保存恢复节点。 |
| 完整备份恢复 | 我的 → 个人完整备份与恢复 | 后台生成 ZIP；上传检查后确认新增恢复。账号、密钥和管理员设置不恢复。任务保留七天，可主动删除。 |

## 输入、原文和预算

- 智能导入支持文字、TXT、MD、DOC、DOCX；提取总量上限为 100,000 字符。
- 长文按分段处理，任务和原始返回保存在本站数据库中，页面关闭后后台仍可继续。
- 不把同名角色自动认定为同一个角色；合并需明确确认。冲突不静默覆盖。
- 查漏中的“原文匹配”只证明字面可定位，不证明语义完整；摘要、缺失状态和否定条件仍需人工检查。
- 必要设定超过上下文预算时会阻止请求并提示；不会静默切掉核心规则。用量是保守估算，需要根据实际服务商模型容量配置。
- 专属世界书的禁用、条目排除和作用范围会生效。已进行故事保留原文版本；管理页修改会影响新故事，旧故事需明确同步角色卡更新。
- 备份上传和解压总量分别不超过 100 MiB，最多 10,000 个文件，最大压缩比 100。恢复默认新增副本，进行中的任务恢复为失败，导入历史恢复为归档。
